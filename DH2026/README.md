# DH2026 LEAF-Writer Commons Workshop
## 'LEAF-Writer Commons: An Introduction to a Lightweight Web-Based Tags-Off TEI+RDF Editor'

This is a repository for 'LEAF-Writer Commons: An Introduction to a Lightweight Web-Based Tags-Off TEI+RDF Editor' a workshop 
at ADHO DH 2026 in Daejeon, South Korea. The workshop takes place on 27 July, and is being presented by James Cummings as a representative of the LEAF-VRE team.

The repository contains workshop materials and sample files for the DH2026 workshop on LEAF-Writer as well as files for the Dynamic Table of Contexts demonstration. 

* Access [LEAF-Writer Commons](https://leaf-writer.leaf-vre.org/)
* Access the [Dynamic Table of Contexts Commons](https://dtoc.leaf-vre.org/)
* Access the [LEAF-VRE site](https://www.leaf-vre.org/)

The sample text for our exercises included herein is Canto IV from Dante's _Inferno_. The text is offered in English, French, German, Italian, Japanese, Korean, and Spanish.
